# Вопросы представителям СНО

Посетители задают вопросы без аккаунта через `/questions`, блок контактов на `/about` и формы разделов `/conferences` и `/conference-announcements`.

## Собственная система

В полной PHP-версии POST `/questions` проверяет имя, почту, тему, текст и согласие, сохраняет обращение в PostgreSQL и уведомляет организаторов внутри приложения. Очередь `/manage/questions` доступна только организатору. Ответ отправляется представителем вручную на указанную посетителем почту; автоматической отправки email сейчас нет. Обращения не включаются в публичный экспорт.

Для связи Pages с запущенным PHP-сервером:

1. Разместите сервер по инструкции [DEPLOYMENT.md](DEPLOYMENT.md).
2. В GitHub → Settings → Secrets and variables → Actions → Variables создайте **repository variable** `QUESTIONS_ENDPOINT`, например `https://your-service.onrender.com/api/questions`.
3. Запустите workflow **Publish public preview to GitHub Pages**. Форма отправит JSON на сервер и покажет подтверждение только после успешного ответа. При ошибке текст останется в форме.

POST `/api/questions` принимает те же поля и возвращает HTTP 201 с `message` при сохранении; ошибки валидации — HTTP 422. CORS разрешает `https://akitwra.github.io` и не передаёт cookies. Для собственного домена обновите `config/cors.php`. API не использует авторизованную сессию и исключён из CSRF-проверки; обычная форма `/questions` защищена CSRF. Ограничение частоты — пять запросов в минуту с одного IP, есть скрытое поле против простых ботов.

## Google Форма

Создайте Google Форму для имени, контакта и вопроса. Убедитесь, что настройки формы соответствуют желаемому доступу посетителей. В той же вкладке GitHub Variables задайте `QUESTIONS_FORM_URL` со ссылкой вида `https://docs.google.com/forms/d/e/.../viewform` или `https://forms.gle/...` и повторно запустите Pages workflow.

Вместо собственной формы появится кнопка перехода в Google Форму. Для полной серверной версии ту же переменную можно добавить в Render. Приоритет имеет Google Форма, если её ссылка задана.

Пока не настроен ни Google Forms URL, ни серверный endpoint, на Pages показаны поля с пояснением о неподключённом приёме. Кнопка отправки отключена: сайт не сообщает о получении неотправленных вопросов. Реальную ссылку и серверный адрес нужно получить у владельца аккаунтов; вымышленные обработчики не используются.
