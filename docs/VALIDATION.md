PHPUnit проверяет ключевые переходы, закрытый доступ, ограничения ролей, повторные заявки, уникальные индексы, ограничение мест, приватную ссылку события, уточнение/отзыв/отказ, идею, помощь/паузу, материалы, уведомления, назначение координатора, доступность наставника, отдельную публикацию/отзыв согласия и отсутствие научных прав у участника, которому позднее назначили роль наставника.

Проверка браузером действительно сохраняет данные в локальной демонстрационной базе. Созданный студент явно называется «Участник · браузерная проверка». Скриншоты в `docs/previews/` сделаны с работающего Laravel-приложения, не из макета.

Автоматический axe-прогон не является полной сертификацией доступности. Render пока не развёрнут: production-образ проверен локально. Университетский SSO, почтовая доставка и восстановление опубликованного snapshot в новой облачной задаче не проверялись. Настройки установки и запуска сохранены в черновике среды; публикация среды и размещение полного PHP-приложения остаются отдельными действиями. GitHub Pages публикует только отдельное публичное превью.

Обновление конференций: PHPUnit проверяет гостевую отправку, согласие, валидацию, ограничение частоты, CORS, приватность очереди и экспорт без обращений. В Google Forms / на внешний сервер реальные вопросы в ходе проверки не отправлялись.

Новый интерфейс проверен в браузере: пять публичных страниц на четырёх ширинах, гостевая отправка с настоящим CSRF, отсутствие ссылок на аккаунты, поиск конференций, раздел предстоящих событий и мобильное меню. На пяти новых/обновлённых страницах axe не нашёл нарушений WCAG A/AA. Клиентский транспорт вопросов отдельно проверен с подставным приёмником: ошибка сохраняет введённый текст, подтверждённая отправка очищает форму; внешние сообщения не отправлялись. Реальный локальный API без сессии вернул HTTP 201.
